# Dedicated Leak Alarm

A single-sensor alarm for one **known target** — the case where MOX sensors are genuinely
good, because selectivity is not required.

- **Tier:** recipe.
- **Claim:** `leak-alarm`, evidence linked.
- **Limits:** one dedicated target sensor; **not** a replacement for certified toxic-gas
  detectors. We never claim open-world identification.
