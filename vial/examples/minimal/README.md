# Minimal Change Log

The smallest complete Vial. It exists to show the whole contract in one place:

- a manifest that passes the policy gate (risk framing, field notes, one real citation);
- a sandboxed `ui.html` that reads only the host snapshot and series window;
- host transforms and a trajectory declared by the Vial, computed and persisted by the host;
- a single-unit watch armed only when the author enters a limit.

```
noses lint .
noses test .
```

The suggested limit in the panel is `4 × measured cv` — the rig's own noise floor. It is a
starting point in ΔR/R₀, not concentration and not a claim about the sample.

This is a reference, not a product. The gate's job is to keep it honest; the app's job is
to enforce it.
